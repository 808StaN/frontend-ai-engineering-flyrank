# Frontend AI Engineering - FlyRank

Capstone repository for the **Frontend AI Engineering** track at FlyRank.

## About

This project explores AI-assisted frontend development workflows using modern tooling and best practices.

## Tech Stack

- **Runtime:** Node.js (LTS)
- **Version control:** Git + GitHub
- **IDE:** [Cursor](https://cursor.com/) with AI-assisted coding
- **Commit style:** [Conventional Commits](https://www.conventionalcommits.org/)

## Getting Started

```bash
git clone <repository-url>
cd frontend-ai-engineering-flyrank
```
