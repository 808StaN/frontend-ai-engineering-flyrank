# FE-05 playground

Standalone Vite + React + TypeScript exercise for accessible Modal, Tabs, and Disclosure widgets. It is not part of the Next.js capstone app.

```bash
cd playground
npm install
npm run dev
```

Open the URL Vite prints, then test with keyboard only.

```bash
npm run lint
npx tsc --noEmit -p tsconfig.app.json
npm run build
```
